# Research ethics and data gaps

PDF page 7 describes secondary data and satellite imagery as a non-invasive approach and marks the UREC-form question as Yes. The supplied nine-page PDF does not establish an independently verified approval record.

There is a scope question to resolve: the methods discussion also mentions surveys and site visits. Before treating these as part of an implemented study, establish what actually happened, which participants or observations were involved, and which documented procedures applied.

| Missing record | Why it is needed |
|---|---|
| Relevant approval documentation | Establishes the scope and status actually recorded |
| Data inventory and access terms | Separates public information from restricted inputs |
| Survey protocol, if used | Clarifies recruitment, consent, questions, and response handling |
| Fieldwork protocol, if used | Identifies what was observed, where, and how |
| Publication decision for raw records | Avoids assuming that report publication authorises raw-data publication |

This is an evidence inventory, not a determination of legal compliance or a claim that approval was absent. The original assignment prompts remain documentary content.
